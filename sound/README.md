# Buana Academy Studio - Sound Directory

This directory is an optional storage location for user-provided MP3 or WAV audio assets.

### Procedural Web Audio Engine
The Buana Academy Studio Transition Engine features a zero-dependency, built-in procedural Web Audio API synthesizer (`js/audio-engine.js`). It synthesizes:
- **Tibetan Singing Bowl**: ~280Hz with beating binaural overtones and warm synthetic convolution reverb.
- **Deep Resonant Double Gong**: Low ~110Hz metallic inharmonic strikes for session wrap-ups and boundaries.
- **Soft Two-Tone Chime**: Aerodynamic F5 → A5 chime.
- **Zen Temple Bell (Keisu)**: Meditative high-frequency strike with sparkling overtones for Dzikir Pagi.
- **Adzan Call to Prayer Resonance**: Spiritual harmonic sequence with deep reverberation for the 5 daily prayers (Subuh, Dzuhur, Ashar, Maghrib, Isya).

### Multilingual Voice Synthesis & Spiritual Routine
- **Dzikir Pagi**: Spoken morning remembrance announcement in Sundanese, English & Arabic.
- **Shalat Dhuha**: Mid-morning reminder to take a pause for wudhu and Dhuha prayer.
- **Pre-Prayer Reminder (Isti'dad)**: T-10m notice before each of the 5 prayers to perform wudhu and arrange prayer mats.
- **5 Daily Adzans**: Spoken call to prayer welcoming members to stand together for congregational prayer.
- **Dzikir Petang**: Spoken afternoon remembrance announcement following Ashar prayer.

### Custom Audio Files (Optional)
If you wish to host custom MP3 files for chimes or announcements:
1. Drop your `.mp3` or `.wav` files directly into this directory (e.g., `sound/custom-chime.mp3`).
2. Test them in `audio-test.html` using the path `sound/custom-chime.mp3`.
3. They will be automatically deployed statically alongside the app on GitHub Pages!
